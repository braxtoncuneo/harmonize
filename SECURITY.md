# Security policy

Please do not report security problems in public issues.

Report them privately through GitHub: on the repository's **Security** tab,
choose **Report a vulnerability**. Include what you found, how to reproduce
it, and which version or commit you used. We will acknowledge the report and
keep you informed while we work on a fix.

Fixes are made on `main` and included in the next release; older releases are
not patched.
