# C++ API

The reference for Harmonize's headers-only C++ library is generated by
Doxygen and published alongside this site:

<p><strong><a href="cpp/index.html">Open the C++ API reference →</a></strong></p>

(The reference is a separate Doxygen site, so it is linked rather than
cross-referenced.)

To use the library, add the directory containing `harmonize.h` to your
include path. With the Python package installed, `harmonize.get_include()`
returns it:

```sh
nvcc -I "$(python -c 'import harmonize; print(harmonize.get_include())')" ...
```
